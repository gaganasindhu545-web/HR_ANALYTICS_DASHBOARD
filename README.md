# HR Analytics Dashboard

## Project Overview

The HR Analytics Dashboard is an interactive Streamlit application for analyzing employee data and understanding employee attrition patterns.

The project provides data analysis, visualizations, employee risk analysis, and an attrition prediction model.

## Features

- Employee attrition analysis
- Interactive HR data visualizations
- Department-wise attrition analysis
- Employee risk and performance analysis
- Attrition prediction
- Data exploration and analysis
- Interactive Streamlit dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Dataset

The project uses an HR Analytics dataset containing employee information such as:

- Age
- Department
- Job Role
- Monthly Income
- Job Level
- Job Satisfaction
- Work-Life Balance
- Overtime
- Years at Company
- Attrition
